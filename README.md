# entelecheia - 精子检测 YOLOv8 完整工作流

## 项目简介

本项目是一个完整的精子检测系统工作流，涵盖从数据采集、标注、模型训练到推理部署的全流程。基于 YOLOv8 目标检测算法，实现显微镜下精子头部的自动检测与计数。

## 目录结构

```
entelecheia/
├── 标注工具/                          # 数据采集与标注工具集
│   ├── 摄像头连续录制工具.py           # 摄像头视频录制（支持HY500B适配模式）
│   ├── 视频抽帧工具.py                # 视频抽帧为图片（支持批量、自动裁剪正方形）
│   ├── 人工辅助数据核查工具.py         # 人工核查标注数据（红框可视化、批量翻页）
│   ├── 自动标注工具.py                # YOLO模型自动标注（红框已有+黄框新增）
│   ├── ai自动标注工具.py              # AI大模型自动标注/核查（火山引擎API）
│   ├── ai自动标注工具_macQwen.py      # AI大模型自动标注（Mac本地Qwen模型版）
│   ├── 精子标注系统.py                # 集成以上所有工具的统一UI系统
```

## 工具使用说明

### 1. 摄像头连续录制工具
- 自动检测可用摄像头
- 可设置录制时长、连续录制组数、保存路径
- 支持 HY500B 摄像头专属适配模式（亮度、对比度、饱和度、增益、分辨率可调）
- 等比实时预览缩放

### 2. 视频抽帧工具
- 导入视频，显示视频时长
- 自由选择抽取图片数量
- 支持批量导入视频，统一参数设置
- 可选「自动裁剪为正方形」（裁掉两边保留中间）
- 后台线程批量导出，双进度显示

### 3. 人工辅助数据核查工具
- 导入图片与坐标文件，自动匹配对应
- 红框可视化已有标注
- 键盘快捷键：A上一张、D下一张、S取消、W确定保存
- 支持重叠框自动删除（红-红、黄-红，阈值可调）
- 自动批量确认模式（可设置翻页延时）

### 4. 自动标注工具（YOLO模型版）
- 基于已训练的 YOLO 模型进行推理
- 红框显示已有坐标，黄框显示模型新增坐标
- 与红框重叠超过阈值的黄框自动删除
- 已有坐标文件的图片单次新增超过20个自动跳过（防坐标偏移）
- 支持覆写原坐标文件或新建

### 5. AI自动标注工具（大模型版）
- **自动标注模式**：无坐标文件时，AI直接生成标注
- **核查模式**：有坐标文件时，AI修正错误、补全遗漏、删除误标
- 支持思考模式（深度推理）和快速模式
- 多线程并发处理，全局限流保护
- 坐标量纲自动识别（0~1归一化 / 像素 / 0~1000）
- 数据集先验约束：含精子画面数量≥20，空画面输出空坐标文件
- 支持环境变量非交互模式（可在SSH/服务器运行）
- **macQwen版**：指向 Mac mini 本地 Qwen3.8-27B 视觉模型

### 6. 精子标注系统
- 集成以上所有工具的统一 UI 界面
- 多线程调用，保障流畅
- 一站式完成：录制 → 抽帧 → 标注 → 核查

## 模型训练

### 训练配置
| 模型 | 分辨率 | Batch | 训练轮数 | 早停 | mAP50 |
|------|--------|-------|----------|------|-------|
| KaLos618 | 640 | 16 | 100 | 20 | - |
| NeiKos496 | 960 | 16 | 120 | 30 | - |
| PoleMos600 | 1280 | 8 | 150 | 30 | 0.892 |

### 启动训练
```bash
# Windows
python train.py

# Mac mini (MPS加速)
python train_mac.py
```

### 训练产物
每个模型目录包含：
- `weights/best.pt` - 最佳权重（未纳入版本控制，需单独获取）
- `results.csv` - 训练指标数据
- `results.png` - 训练曲线图
- `confusion_matrix.png` - 混淆矩阵
- `BoxPR_curve.png` - PR曲线
- `BoxF1_curve.png` - F1曲线
- `train_batch*.jpg` - 训练批次示例
- `val_batch*_pred.jpg` - 验证预测示例
- `args.yaml` - 训练参数配置

## 数据集格式

### YOLO 格式
- 图片：PNG/JPG，建议正方形（640×640 / 960×960 / 1280×1280）
- 标签：同名 `.txt` 文件，每行一个目标
```
class x_center y_center width height
```
- 坐标均为 0~1 归一化值
- 精子检测：class=0，框宽高固定 0.015625（1280分辨率下对应20px）

### 数据集目录结构
```
dataset/
├── images/
│   ├── train/     # 训练集图片
│   └── val/       # 验证集图片
└── labels/
    ├── train/     # 训练集标签
    └── val/       # 验证集标签
```

## 推理部署

### 生产端
- 已打包为 `NeiKos496_Detector.exe`（未纳入版本控制）
- 目标硬件：Intel N100 + 16GB 内存
- 目标帧率：8 FPS+
- 支持摄像头实时检测和视频文件推理

### ByteTrack 目标跟踪
- 配置文件：`bytetrack_sperm.yaml`
- 可用于视频中精子的跟踪与计数

## 注意事项

1. **大文件未纳入版本控制**：模型权重（.pt）、数据集图片、视频文件、虚拟环境均通过 `.gitignore` 排除，需单独传输
2. **AI标注工具需要API密钥**：火山引擎版需配置 `API_KEY`，macQwen版需 Mac mini 上 Qwen 服务运行中
3. **训练耗时参考**：1280分辨率 + batch=8 + 150轮，Mac mini M系列约需6-8小时
4. **坐标偏移防护**：自动标注工具中，已有坐标文件的图片单次新增超过20个会自动跳过，防止批量坐标偏移错误
